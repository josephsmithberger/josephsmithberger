# Joseph Smithberger

I'm a student developer from Maryland. I build games, iPhone apps, and tools for creative work, and contribute documentation and tutorials to Xogot.

## Released work

**[Mind Garden](https://store.steampowered.com/app/3045100/Mind_Garden/)** — My first released game, built in Godot with artwork scanned from original crayon drawings. A short narrative adventure about memory, exploration, and keeping a journal. [Development retrospective →](https://josephsmithberger.com/blog/posts/first-game)

**[weBump](https://webump.app)** — My iPhone app for discovering people you pass in real life. It uses Bluetooth encounters to create connections, with opt-in profile sharing and an API for connected games. [How it works →](https://josephsmithberger.com/blog/posts/webump-1-5)

## Selected public projects

- **[weBump Racing Demo](https://github.com/josephsmithberger/Racing-weBump-Demo)** — A playable example of the weBump Connected Games API: people you've bumped become racing rivals through shared ghost replays. Built on Kenney's racing starter, with my API integration, replay system, and gameplay additions. [Play →](https://webump.app/demo) · [Developer tutorials →](https://developer.webump.app/racing.html)
- **[Native Metal path tracing for Godot](https://github.com/josephsmithberger/godot-metal-path-tracing)** — An experimental Apple Silicon port of the path-tracing work in NVIDIA's Godot fork, with screenshots, benchmarks, and reproducible tests. The README explains the implementation, limitations, and how I used AI during development.
- **[Xogot documentation](https://github.com/josephsmithberger/XogotDocs)** — My contribution fork for documentation and tutorials for Xogot, the native Godot editor for Apple devices. Selected merged contributions: [running code in the editor](https://github.com/xibbon/XogotDocs/pull/18), [GDScript reference](https://github.com/xibbon/XogotDocs/pull/27), and [updating the first 2D game tutorial](https://github.com/xibbon/XogotDocs/pull/41).
